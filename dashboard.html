Términos y condiciones de uso

Al crear una cuenta, iniciar sesión, recargar saldo o solicitar cualquier servicio dentro del panel, el usuario reconoce y acepta estos términos y condiciones.

El saldo abonado al panel se utiliza exclusivamente para servicios dentro de la plataforma. El saldo no es reembolsable fuera de la plataforma, salvo que Novyra Services confirme un error real atribuible al servicio.

Si la cuenta no registra uso del panel durante 29 días naturales, el saldo disponible podrá caducar por inactividad. El usuario es responsable de dar seguimiento a sus solicitudes y mantener activa su cuenta.

La información personal, documentos, CURP, NSS, RFC y demás datos proporcionados se usan únicamente para obtener el servicio solicitado. La información no se reutiliza para otros fines y se elimina de la base operativa cuando deja de ser necesaria para la prestación o aclaración del servicio.

Las cuentas con actividad sospechosa, intento de fraude, duplicidad intencional de comprobantes, abuso del sistema o uso no autorizado podrán ser suspendidas o dadas de baja sin previo aviso.

Los reclamos solo serán procedentes cuando exista evidencia verificable de error real en el servicio, pago o entrega. Las aclaraciones deben enviarse desde el módulo de Solicitud de Aclaración del panel.
